Hospital Management (FHIR)

Outpatient clinic and small-hospital management for Odoo 20, with an HL7 FHIR R4 API

Clinical workflow

  • Patient registration with automatic medical record numbers
  • Appointments with double-booking protection and check-in
  • Visits that lock when finished; admin-only amendments with a reason
  • Vital signs (LOINC), diagnoses (ICD-10), prescriptions (WHO ATC, SNOMED CT routes)
  • Laboratory orders, worklist, results with normal ranges, corrections with a reason
  • Printable prescriptions

Billing, privacy and interoperability

  • Cash and insurance invoices through Odoo Invoicing, including supplementary invoices
  • Roles: receptionist, nurse, doctor, lab technician, cashier, administrator
  • Tamper-proof access log of every view, list, export, script and API read
  • Multi-company (branches) separation
  • FHIR R4 API with API-key authentication, paging, AuditEvent and Patient/$everything

After installing

  1. Invoicing > Configuration > Settings: choose your Fiscal Localization and save.
  2. Settings > Users: give each staff member a Hospital role.
  3. Hospital > Configuration: link practitioners to users; set prices and lab normal ranges.
